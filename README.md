# 🚀 C&T

🔗 **Acesse o site:**  
https://pedrohenriquecienciaetecnologia.netlify.app


## 📌 Sobre o projeto

A **C&T** é um site simples desenvolvido para um evento escolar de Ciência e Tecnologia durante o ensino médio.

A proposta foi criar uma página que apresentasse:

- 📅 O cronograma das apresentações  
- 🎓 Cursos relacionados à área de tecnologia  
- 🌌 Temas como Astronomia, Tecnologias e Programação  
- 👥 Os participantes do projeto  

Foi um projeto voltado principalmente para organização de conteúdo e estruturação de uma página completa.


## 🛠️ Tecnologias utilizadas

- HTML  
- CSS  
- JavaScript (Vanilla JS)


## ⚙️ Funcionalidades

- 📂 Menu lateral que abre e fecha ao clicar no ícone no canto superior esquerdo  
- 🔗 Navegação por âncoras entre as seções  
- ⌨️ Pequena animação de digitação na parte inicial  
- 📱 Layout adaptado para telas menores  

O JavaScript foi utilizado apenas para controlar a abertura e fechamento do menu lateral e alguns comportamentos simples da interface.
